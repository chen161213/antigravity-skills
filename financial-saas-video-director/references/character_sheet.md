# 人物身份表提示词模板（全中文 · 16:9）

每次必须同时输出 A / B / C 三套。三套共用"基础段 + 版式段 + 光影段"，只替换"服化道段"。

## 一、版式（四视角，全员直立）

16:9 横幅，纯净浅中性灰影棚背景。
- **左侧**：占画面大比例的标准中全景/膝盖景核心主图。直立挺拔站姿，笔直站立；头顶预留 25%~30% 留白，下边缘切在膝盖处（大腿中下部）；双手自然轻叠于腹前，自信从容微笑。严禁坐姿，严禁椅子与高脚凳。
- **右侧**：并排 3 个完整全身直立视角，从左至右依次为：全身正面（双手交叠腹前）、全身正侧面、全身正背面。
- 严禁出现"大头贴、仅到腰部的半身特写、坐姿"，防止 H3 误判为坐姿或弯腿。

## 二、质感档位（二选一，默认精致档）

- **精致档（默认）**：极致冷白皮，细腻白皙如凝脂，水光肌底，白里透红，纯净通透。
- **自然质感档**：通透冷白皮，肤色干净自然，保留细微真实的皮肤质感与自然光泽，妆面轻薄克制，整体可信、不过度修饰。投放对象偏保守、或素材量大需降低"AI 感"时选用。

两档都不使用粗糙、暗沉、细纹类词汇。

## 六、使用说明

1. 输出时给三个独立的完整可粘贴文本（基础段 + 对应服化道段 + 版式光影段已拼好），不要让用户自己拼。
2. 发型尽量选"收拢型"，减少走动时发丝飘动造成的画面抖动。
3. 视频生成时，`<Picture 1>` 只提取人物容貌与服饰，严禁复制多格排版，这条要写进视频提示词。
