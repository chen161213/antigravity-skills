## 一、数值表（全篇唯一数据来源）

所有提示词里的速度、视距、留白必须从本表取值，不得自行改数字，也不得在同一条提示词里出现两套数值。

| 项目 | 取值 |
|---|---|
| 成片画幅 | 9:16 竖屏 |
| 单次生成档位 | **硬性锁定为 10 秒 或 15 秒**（MiniMax H3 原生固定选项，不支持任意自定义时长） |
| 10 秒档字数预算 | 4~5 字/秒；单个大镜头 ≤ 45 字（建议 40~44 字） |
| 15 秒档字数预算 | 4~5 字/秒；单个大镜头 ≤ 70 字（建议 65~70 字） |
| 时间戳跨度 | 必须从 `00:00.00` 完整覆盖至该档位终点（`00:10.00` 或 `00:15.00`），最后 1 秒统一为腹前收势，严禁中途截断 |
| 景别 | 开阔中全景 / 膝盖景（MLS） |
| 头顶留白 | 25%~30%（写 28%） |
| 眼线位置 | 画面垂直方向上三分之一线 |
| 下边缘 | **严格卡在膝盖骨下方/露出完整膝盖**，完整展现西装裙裤与膝关节轮廓，**严禁切在大腿根部或腰部**，脚踝、鞋底不入镜 |
| 机位视距 | 3.5 米恒定（中远视距），人物在竖屏画面中仅占 60%~65% 高度，体量全程恒定 |
| 档位 1 站定 | 人物净位移 0；双脚站稳，身体重心随呼吸与语气轻微左右晃动；摄影机固定（C5） |
| 档位 2 假走（首推默认） | 人物走走停停，每 3 秒仅微挪半步，净位移约 0.1 m/s；绝大部分时间接近原地从容踱步；摄影机固定或极平缓微后退 |
| 档位 3 慢速真走（高危慎用） | **【实操避坑警示】**：MiniMax H3 看到"直行""向前走"极易触发默认的快走赶路动画，导致 10 秒内连跨数排工位、背景飞速后退！若使用，**严禁使用"直行""快步"词汇**，必须写明"极其缓慢地仅迈出一步后立即停步踱步"，摄影机保持固定，单次 ≤ 3 秒。日常商业投流**强烈推荐全面使用档位 2（原地假走）或档位 1（站定）**，画面最稳、背景不飞退。

**为什么摄影机速度要等于人物净位移**：摄影机后退而人物不跟进，视距会越拉越远；人物前进而摄影机不退，会越走越近。两者速度相等才能让"视距恒定"成立。旧版"人物每 3 秒半步 + 摄影机 0.3~0.4 m/s"互相矛盾，已废弃。

**为什么必须对齐 10 秒或 15 秒**：MiniMax H3（海螺 AI）后台没有任意秒数输入框，只有 10s 和 15s 按钮。若提示词只写到 7s 或 8s，生成出的 10s 视频在后半截人物读完词就会出现尴尬发呆与动作形变。因此提示词必须打满对应档位的完整时长。

## 二、步态三档

按台词逻辑选档，一个大镜头里建议"走—停—走"变化，而不是全程同一档。

**档位 1 · 站定**
- 用于：CTA、关键结论、需要强调的转折句。
- 表现：双脚站稳，重心随呼吸与语气从容轻微左右晃动，手势为主要动态。摄影机固定（可加 ≤0.05 m/s 的极缓推进增加生命力）。

**档位 2 · 假走（默认）**
- 用于：大部分讲解、铺垫、列举。
- 表现：走走停停，边说边轻微位移，每 3 秒仅微迈半步，绝大部分时间接近原地从容踱步。
- 必含四组黄金步态词（每个含档位 2/3 的大镜头只写一次，写进【步态】块）：
  `极其缓慢地漫步` · `悠闲小步踱步` · `步伐轻缓慢节奏` · `走走停停，边说边轻微位移`
  并附声明：`极低步频（每 3 秒仅极其轻微迈出半步微调，绝大部分时间接近原地从容踱步）`。

**档位 3 · 慢速真走（点缀）**
- 用于：开场 Hook 的前 2~4 秒，或段落间的转场；让整条片子有真正"走播"的运动感。
- 限制：仅膝盖景；脚步落在画面外；单次 ≤ 4 秒；每个大镜头最多 1 次；**不用于 CTA**；结束时必须过渡到档位 1 或 2，并在该秒写明"缓步停稳"。
- 表现词：`平稳从容地缓步直行，步幅小而均匀，肩部与头部稳定不起伏`。

纯档位 1 的大镜头：【步态】块改写为"站定，重心从容轻微左右晃动"，四组黄金步态词可省略。

## 三、机位库（每个大镜头选一种并写清动线）

| 编号 | 机位 | 适用 | 提示词写法 |
|---|---|---|---|
| C1 | 正前方缓退 | 档位 2/3 默认 | 摄影机在视平线高度、3.5 米视距平稳直线后退，速度与人物净位移一致 |
| C2 | 侧前方 45° 跟拍 | 档位 2，想要立体感 | 摄影机位于人物前方偏左（或右）45°，同速平移跟随，视距 3.5 米 |
| C3 | 侧面平行跟拍 | 档位 2/3，背景视差最自然、透视变形最小 | 摄影机在人物侧面平行同速移动，人物面部约 3/4 朝向镜头 |
| C4 | 固定机位，人物走近停下 | 档位 3 → 1 | 摄影机固定，人物从远处缓步走近并在 3.5 米处停稳（落点须在膝盖景范围） |
| C5 | 固定机位 | 档位 1 | 摄影机固定，仅允许极轻微呼吸感推进 |

**接力与硬切的取舍**：
- **尾帧接力段**：首帧就是上一段尾帧，机位必须保持不变（同为 C1 或同为 C3），不要在接力段里强行改变机位角度，否则容易变形、跳脸。
- **换机位**：该段不接力，改用首段写法（`<Picture 1>` 身份表 + `<Picture 2>` 场景基准图重开），在剪辑里硬切；光源方向、人物站位、服装沿用上一段记录。
- 整条片子建议"接力 1~2 段后硬切换一次机位"（如 C1→C1→C3→C5），避免投流素材审美疲劳，同时硬切本身也是口播片常见的节奏手段。

## 四、手势映射（按台词功能，不按秒数）

腹前轻叠是"港湾"（起点与终点），手势在语调重音处"起手 → 舒展强调 → 回归港湾"。

| 台词功能 | 手势 |
|---|---|
| 痛点反问 / 提问 | 单手自腹前抬至胸前，食指轻点或掌心自然微张，语尾回落 |
| 痛点陈述 / 共鸣 | 单手克制递进（小幅度），可配合微皱眉后平复 |
| 转折 / 价值释放 | 双手自腹前向两侧自然对称微展，掌心微侧向镜头，配合舒展微笑 |
| 功能点列举 | 单手依次轻点，**最多 2 下**，每下对应一个功能词 |
| 结论 / 肯定 | 单手胸前笃定单点，随后双手回落腹前交叠 |
| CTA | 单手朝画面左下方向轻柔指引（对应"点击左下角"），随后回落；末 1 秒收势 |

AI 稳定性：手指自然舒展放松；手势幅度小而柔和；避免双手高频交叉、抓握、数手指等复杂动作；避免整段双手焊死不动。

## 五、眼神与声线

**眼神**：Hook（首句）与 CTA（末句）直视镜头；中间讲解段约 70% 时间看镜头，偶尔视线轻扫前方或略低，显得自然，不发呆盯视。

**声线锚定**：每个大镜头必须逐字一致地写入同一段声线描述，以抑制多段生成的音色漂移。模板：

`(S1) 声线：28岁左右女性，清亮温润、略带知性的标准普通话，中等语速约4.5字每秒，语调亲和笃定，气息自然，音色与前后镜头保持完全一致。`

若 MiniMax H3 提供参考音色/声音克隆入口，优先使用，并在说明里提醒用户；若仍出现音色不统一，建议成片后统一做配音替换或后期调音。

## 六、跨段连续性

每个大镜头结束时记录并传给下一段：
1. **行进方向**（画面左→右 / 右→左 / 朝镜头 / 站定）
2. **人物位置**（画面左 / 中 / 右）
3. **光源方向**（如：窗光自画面左侧入射）
4. **收势**：每段最后 1 秒统一收成"双手腹前交叠、身体稳定、表情自然收束"，方便截尾帧。

下一段提示词的 Shot 1 必须沿用上述方向、位置与光源。

场景动线：多段拼接时，参照 `scene_library.md` 中该场景的"动线标志物"，让每段背景出现不同的路标（绿植 → 玻璃会议室 → 窗前吧台），观众才会觉得人真的走了一段路。

## 七、语法与模板

**官方语法要点**
- 首个大镜头：`对于目标视频，在目标视频的 0.00 秒处，完全参考 <Picture 1>…… 并融合 <Picture 2>……`
- 后续大镜头：`对于目标视频，在目标视频的 0.00 秒处，完全参考 <Picture 1>（来自上一镜头最后一秒尾帧）`；若支持多参考图，再加 `<Picture 2>` 为身份表，仅提取人物五官与服饰。
- 说话人与口型：`(S1)` 声明，台词置于 `<d>[普通话] 台词 </d>`。
- 小镜头标记 `[Shot N]` 后写时间点（如 `00:03.50`）。

**主版模板（大镜头 1，双参考图）**

```text
对于目标视频，在目标视频的 0.00 秒处，完全参考 <Picture 1>（仅提取人物五官神态与服饰，严禁复制多格排版，裁切至膝盖处），并融合 <Picture 2> 的场景透视与光线。

综合多模态描述:
【全局】成片画幅9:16竖屏；开阔中全景/膝盖景（MLS），画面顶部保留28%开阔留白，人物发顶远离上边缘，双眼位于画面垂直方向上三分之一线，下边缘卡在膝盖处，脚踝与鞋底不入镜；摄影机视平线高度，保持3.5米恒定视距，人物体量全程恒定。
【声线】(S1) 声线：28岁左右女性，清亮温润、略带知性的标准普通话，中等语速约4.5字每秒，语调亲和笃定，气息自然，音色与前后镜头保持完全一致。
【步态】（含档位2/3时写入）极其缓慢地漫步、悠闲小步踱步、步伐轻缓慢节奏、走走停停，边说边轻微位移；极低步频（每3秒仅极其轻微迈出半步微调，绝大部分时间接近原地从容踱步）；身体重心随讲话从容轻微左右晃动。
【机位】{C1/C2/C3/C4/C5 写法}，行进方向：{方向}，人物位于画面{左/中/右}，光源自画面{左/右}侧入射。

[Shot 1] 00:00.00 {档位}。{表演：站位/表情/眼神}，{手势按台词功能写}。(S1) {语气}说道：<d>[普通话] {台词} </d>
[Shot 2] 00:0X.XX {档位变化点}。{动作差异}，(S1) {语气}：<d>[普通话] {台词} </d>
[Shot 3] ……
最后1秒收势：双手自然交叠于腹前，身体稳定，表情自然收束。

【禁令】严禁快走、急促赶路、大跨步或快速位移；严禁人物加速逼近或贴近镜头；严禁头部大特写与腰部以上中近景；严禁头顶留白小于25%；严禁下半身滑步与穿模；严禁全程双手僵死不动，也严禁大幅甩手或手指抽搐。

整体音景:
{场景声学环境，如：高端科技公司大平层通透走廊的自然安静混响，说话人语音清晰饱满，带自然呼吸感}

非剧情音乐:
无
```

**后续大镜头**：把第一行换成尾帧接力指令；`<Picture 2>` 视支持情况改为身份表；其余结构不变，Shot 1 开头写"顺畅接续上一镜头的运镜动线与站位"。

**写作要求**
- 【步态】块和【禁令】块各出现一次，Shot 内只写动作差异，不重复堆词。
- 数值只能来自"一、数值表"。
- 每个 Shot 都要标明本段所处档位与手势对应的台词功能。

## 八、保底简化版（每个大镜头必给）

主版翻车（滑步、手变形、口型错位）时直接换用。写法：
- 档位固定为 **1 站定**（若原本是档位 3，则改为"从画面内已站定"）；
- 摄影机固定（C5）；
- 手势只保留"腹前交叠 + 一次单手轻点"；
- 台词、声线锚定、画幅、景别、禁令保持不变；
- 单 Shot 写完，不分小镜头。

格式：在主版后加 `【保底版】` 标题，给出完整可粘贴文本。
