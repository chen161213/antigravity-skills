## 核心工作流（严格分三阶段，严禁抢跑！）

```
【阶段一：需求确认与剧本提案（必须停步等待）】
收到台词 ──> 分析受众与痛点 ──> 询问/推断视频类型与风格 ──> 产出 ≥3 个差异化剧本 ──> 暂停等待选定
                                                                               │
                                                                   用户确认选定（不满意重写）
                                                                               ▼
【阶段二：资产提示词生成（紧扣剧本）】
确认画风 ──> 逐角色输出身份表 ──> 逐场景输出3/4透视图 ──> 输出关键道具/比例图 ──> 暂停确认
                                                                               │
                                                                         用户确认资产
                                                                               ▼
【阶段三：分镜提示词编写（MiniMax 官方多参考）】
10s/15s 原生时长分段 ──> 多素材槽位映射与保留分析 ──> 输出结构化分镜提示词 ──> 剪映拼接指引
```

### 阶段一：需求探询与剧本创作（绝对禁止直接写剧本！）

1. **第 1 步：台词体检与风格探询**
   * 提炼台词的核心信息点、受众（如中小企业老板、年轻白领等）与情绪痛点。
   * **推断 + 明确提问**：
     * 根据台词主动推断 2~3 个适合的视频表现形式（例如：办公室双人对手戏短剧、体面商业走播/访谈、第一人称内心独白实录等）。
     * 主动向用户提问：“您希望做成哪种类型与风格？偏向情景短剧还是专业讲解走播？是否有特定的视觉节奏或人物设定偏好？”
2. **第 2 步：创作并交付 ≥3 个差异化剧本方案**
   * 用户确认风格意向后，提供 **不少于 3 个风格各异的剧本方案**（详见 `references/storyboard_workflow.md`）。
   * 每个方案清晰列出：
     * **方案名称与核心情境**
     * **登场角色列表**（角色A、角色B的名字、身份、人设画像）
     * **场景动线规划**（场景1、场景2等）
     * **分段台词节奏与叙事冲突**
3. **第 3 步：满意度确认环路**
   * 主动暂停，等待用户选择。
   * **满意度保证**：若用户不满意或提出修改意见，立即重写或微调，**直到用户明确确认选定为止**。

---

### 阶段二：资产提示词编写（角色 + 场景 + 关键道具）

用户选定剧本后，根据剧本内容编写全套生图提示词（详见 `references/asset_prompt_spec.md`）：

1. **画风基调确认**：询问画风（如电影胶片质感、哈苏商业摄影实拍、真实职场日常等），或根据剧本基调选定。
2. **角色资产（支持单人 / 多角色）**：
   * 剧本中有几位出镜角色，就为每位角色**单独输出一套 16:9 横幅多视角身份表提示词**。
   * 采用“左侧特写大脸 + 右侧全身正面/背面”的稳定版式。
   * **附带实操避坑提示**：告知用户若生成视频人脸跑偏，可在生图后涂白遮盖全身图面部，强迫模型吃特写大脸。
3. **场景资产（支持单场景 / 多场景，绝不限制死板空镜）**：
   * 剧本涉及几个场景，就出几套场景提示词。
   * 必须融入 **“3/4 角度（Three-quarter angle）”** 与主光源，构建真实纵深空间；根据剧情需要自然呈现环境、道具与背景氛围。
4. **可选关键道具与比例图**：
   * 若剧本涉及关键手持物品（如特殊工具、特定合同封皮、饮品等），生成“道具与主体在同画面的比例关系基准图”。

---

### 阶段三：分镜提示词编写（MiniMax H3 / Hailuo 02 官方多模态语法）

资产确认后，生成最终的视频生成分镜提示词（详见 `references/h3_video_prompt_spec.md`）：

1. **原生时长硬性拆段（对齐 10s / 15s 工具约束）**：
   * 普通话语速按 4~4.5 字/秒计算。
     * **10 秒档**：单个大镜头台词 ≤ 45 字。
     * **15 秒档**：单个大镜头台词 ≤ 70 字。
   * 总视频若长于单段时长（如 30 秒），严格拆解为 3 段 10s 或 2 段 15s 的独立生成片段。
   * 时间戳必须从 `00:00.00` 完整打满到终点（`00:10.00` 或 `00:15.00`），最后 1 秒统一为收势，杜绝末尾发呆。
2. **官方多图参考（Ref2VA）插槽映射**：
   * 提示词头部明确声明素材对应关系：
     - `<Picture 1>` = 角色A身份表
     - `<Picture 2>` = 角色B身份表
     - `<Picture 3>` = 场景基准图
     - `<Picture 4>` = 关键道具/比例图（如有）
   * 连续镜头：同场景同机位使用上一镜头尾帧接力；换场景/换机位采用硬切。
3. **多模态时间轴结构**：
   * 包含：成片画幅（9:16 或 16:9）、景别视距、多角色声线锚定 `(S1)`、`(S2)`。
   * 逐镜头推进：`[Shot N]` 标注递增时间码、机位角度、动作、对白 `<d>[普通话] 内容 </d>`。
   * 独立分轨：`overall_soundscape`（环境音与物理音效）与 `non_diegetic_music`（背景音乐）。
   * 针对性禁令块。
   * **单一高标准版本**：每个分段仅交付这一套高质量完整提示词（无保底版冗余）。
4. **简易剪辑拼接指引**：
   * 输出剪辑拼合顺序、转场建议、字幕切分与音频统一建议。

## 不可违反的铁律

1. **绝对禁止抢跑**：用户没确认风格前，严禁写剧本；没确认剧本前，严禁写资产；没确认资产前，严禁写分镜。
2. **剧本多方案保证**：首轮剧本创作必须至少给 3 个不同方向，不满意必须重写到满意。
3. **原生档位硬性约束**：单镜头时长必须严格对齐 MiniMax 原生档位（10s 或 15s），时间戳必须打满全长。
4. **多角色与多场景动态映射**：严格支持多人对白与多场景切换，绝不焊死单人或单一空镜。
5. **官方语法规范**：严格使用官方 `<Picture N>` 映射、发言人 `(S1)`、`<d>` 对白标签及声画独立分轨。
