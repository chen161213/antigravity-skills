# MiniMax H3 提示词写法要点（中文版）

来源：MiniMax 官方 Video Prompt Writing Guide（基础模式 T2VA/I2VA/FL2VA/L2VA 与全参考模式两份，HuggingFace MiniMaxAI/MiniMax-H3 仓库 docs 目录），并参考公开使用指南（API易、Morphic、Runway、fal 等）。官方两份指南是英文的，**本 skill 把它们的结构和规则转写成中文提示词，格式符号保留**：`<d>…</d>`、`(S1)`、`<scenetrans>`、`<cutoff>`、`<Subject N>`、`<Picture N>`、`<Audio N>`、`[镜头N]` 中的数字与括号。官方没有公布"中文主体是否劣于英文主体"的结论；用户要求只出中文版，不出英文版。若用户工具入口规则不同，以用户工具为准。

## 官方字段对照

| 官方（英文） | 本 skill 中文小标题 | 内容 |
|---|---|---|
| subject_definitions | 参考分工 | 每个参考一行：是什么、取自哪、跟随什么 |
| integrated_multimodal_description / detailed_description | 综合画面描述 | 按镜头按时间的画面、动作、运镜、说话人、台词、画面内声音 |
| overall_soundscape | 整体环境声 | 环境声、动作声、非语言人声，1-4 句，不含台词 |
| non_diegetic_music | 画外配乐 | 人物听不到的音乐，1-3 句，写乐器/速度/节奏/力度 |
| （官方无，用户工具五模块里有） | 限制 | 锁定不变的元素、不要什么、物理防崩句 |

官方 `summary`、`retention_analysis` 是改写器的内部输出（描述保留程度），用户侧提示词不用写。

## 参考标签

| 标签 | 含义 | 本 skill 里对应 |
|---|---|---|
| `<Subject N>` | 可复用的可见内容：人物、场景、服装、道具、风格、动作 | 人物设定图、场景图 |
| `<Picture N>` | 作为具体帧或分镜锚点的图：首帧、关键帧、尾帧 | 本段首帧（尾帧） |
| `<Video N>` | 整段视频关系：编辑源、续写起点、镜头/节奏结构参考 | 本 skill 暂不用 |
| `<Audio N>` | 被复制或参考的音频 | 音色参考 |

- 各类**分别从 1 编号**，编号只表示类内顺序，不表示配对。
- 同一标签在全篇含义不变。
- 仅用来定义人物/场景/服装的图，归入 `<Subject N>`，不要另建 Picture 条目。
- 说话人和音频绑定：`<Audio 1> 是 <Subject 1> (S1) 的音色参考`；说话人 ID 按目标视频里实际发声的先后顺序编，音频定义里只复用，不另编。
- **只参考音色或语速时，不把参考音频里的台词带进目标视频**；只有直接复用音频台词或明确要求重演时，才在 `<d>` 里写原词。
- 如果用户工具界面里是"图1/图2/音频1"，则替换成对应写法并在参考分工里写清用途。**第一次输出时请用户确认。**

## 画面描述怎么写

- 每个细节都要对应看得见或听得见的东西：风格、构图、人物外观与位置、场景道具、动作与反应、切镜、台词、画面内声音。
- 风格放在开头：写实电影、二维动画、三维 CG、黏土、水彩、复古胶片等。
- 首帧起手结构：**首帧锚点 → 动作起势 → 连续发展 → 结果或反应**。人物身份、服装、颜色、关键物件、空间关系保持一致。
- 尾帧（可选）结构：**首帧状态 → 可观察的中间变化 → 差异逐步收窄 → 尾帧状态**，单镜头为主，最后一个镜头必须在片尾到达尾帧。
- 篇幅：官方生成任务约 350-500 英文词（折合约 700-1200 中文字），台词密集时以放下完整台词时间线为准。镜头多、信息量大时把细节分摊到各镜头。

## 镜头与切镜

- 第一个镜头不写时间；后续镜头写 `[镜头2] 在00:03.500，镜头切到……`，时间严格递增且在片长内。
- 普通切镜用"镜头切到 / 切换到 / 转到"；用户明确要求时才用叠化、淡入淡出、划像。
- 切镜要带来新信息（主体、空间、状态、视角、时间）；只是距离或角度微调，改用运镜。
- 单镜头内的秒级节拍（0-3秒 / 3-7秒…）是本 skill 为控制动作量保留的写法，用来细分动作，不是官方的切镜标记。

## 运镜词表（类型＋幅度＋速度）

| 官方 | 中文写法 | 含义 |
|---|---|---|
| Zoom In / Zoom Out | 变焦推近 / 变焦拉远 | 机位不动，改焦距 |
| Push In / Pull Out | 推进 / 拉远 | 机位前后移动 |
| Pan Left / Right | 向左摇 / 向右摇 | 机位不动，镜头水平转 |
| Truck Left / Right | 向左横移 / 向右横移 | 机位水平平移 |
| Tilt Up / Down | 向上俯仰 / 向下俯仰 | 机位不动，镜头垂直转 |
| Pedestal Up / Down | 整机升 / 整机降 | 机位整体升降 |
| Arc Shot | 环绕 | 绕主体弧线移动 |
| Tracking Shot | 跟拍 | 跟随运动主体 |
| Static Shot | 固定镜头 | 机位与镜头都不动 |
| Shake Slightly / Strongly | 轻微晃动 / 强烈晃动 | |
| POV | 主观视角 | 人物视角 |
| Roll CW / CCW | 顺时针滚转 / 逆时针滚转 | 绕镜头轴旋转 |

- 幅度：小幅度 / 大幅度；速度：慢速 / 快速。中等幅度和正常速度省略。
- 写成镜头内的自然动作句：`镜头小幅度慢速推进，朝向她手里折起的信`；不要在句尾堆标签。
- 本 skill 的稳定性原则仍然成立：一个节拍只给一种运镜，不用快速大幅度多轴运动。

## 说话人、台词、声音

- 说话人 `(S1)`、`(S2)`；多人同时 `(S1,S2)`；同一人跨镜头 ID 不变。
- 首次出场立声线：角色类型、年龄、性别、是否在画面内、音高、音色、语速、口音。
- `<d>[中文] 原文</d>` 里只放语言标签和用户给的台词，保留每个字和标点，不翻译不改写；说话人描述、动作、语气放在标签外。
- 标点只保留必要的 ，。？！；完整的陈述、疑问、感叹句在 `</d>` 前分别以 。？！ 结尾。听不清的部分写 `[unclear]`，不要猜。
- 画外音："以画外音说"，台词后接"同时嘴唇保持闭合"。
- 台词跨切镜：前后两处都用 `<scenetrans>`，并写"声音跨镜头连续 / 延续进下一镜头 / 承接上一镜头"。台词被片尾截断：`<cutoff>`。
- 整体环境声：1-4 句一整段，只写环境声、动作声、非语言人声；不重复台词和画面内音乐；仅在用户明确要求全程无声时写"无"。
- 画外配乐：1-3 句，乐器、速度、节奏、力度变化；不写抽象情绪词；无配乐写"无"。

## 画面内文字

画面里真实出现的招牌、屏幕、字幕、标牌文字，用双引号原样写，不翻译。本 skill 默认字幕后期加，所以默认在限制里写"画面内不出现任何文字"，除非剧本里有招牌、手机界面等道具。

## 常见坑

- 上传参考图却不写用途 → 模型自己猜，容易错位
- 只描述一帧静止画面，没有动作 → 人物僵硬
- 完全不写声音 → 音效不可控
- 音频参考单独提交会被拒绝，必须搭配图或视频
- 音色参考里带着上一段台词 → 容易串台，必须写"仅参考声线与语速，不复用台词内容"
- 想改一个元素就整段重来 → H3 支持"指令式编辑"，只改点名的元素，满意的镜头可保留
- 中文台词：官方未公布语言支持清单，建议用户先用短片段测试一次音色与口型再批量出片
- 公开指南的共同建议：先一个主体、一个动作、一个主运镜，台词简短，一次只加一个新参考或新指令

## 跨段一致性

- 每段都传同一张人物参考图，并在提示词里**重复写明**要保留的特征（发型、服装、配饰）
- 每段首帧都用本段独立的首帧提示词生成（镜头之间硬切），不使用上一段尾帧；各段首帧里人物脸型、发型、服装保持一致
- 第1段默认不传音色；第2段起音色参考 = 第1段视频里导出的人物声音，保证声线连续
- 提示词里写明人物身份、服装、发型与首帧严格一致

## 首帧与关键帧预览

- **首帧图**是唯一随视频一起上传的"起始画面"：负责人物长相、服装材质、初始站位和光影。视频提示词只写**动态演变**，不要再重复描述首帧已经固定的服饰花纹、脸型。
- **关键帧预览图**（4×2 带序号宫格，整体 4:3，每格 9:16 竖构图）只用来在出片前预判动作走向和各节拍的长相，**绝不上传到 H3**。
- 首帧来源：每一段都用本段的"首帧画面提示词"把人物图+场景图融合生成；镜头之间一律硬切，不用上一段尾帧。关键帧预览只在第1段出。

## 动作与措辞

- 不用"慢动作""突然变身"等词，容易导致画面崩坏或节奏异常；改写成"匀速、小幅、缓慢抬手约15度"这类**正向物理描述**。
- 单段内不要塞入超过真人实际速度的动作量，动作细化到秒级切片（0-3秒 / 3-7秒 / 7-10秒）。
- 避免快速大幅度多轴运动（又摇又推又变焦），一个节拍只给一种镜头运动。
- 站位用"画面左三分之一/右三分之一""前景/中景/后景"锁定，人物用确定性命名，如 `[主角-A]`、`[对方-B]`。
- 公开指南也建议用正向、明确、以结果为导向的措辞。

## 物理防崩关键词（限制块可直接附上，一律用中文）

`动作速度符合真人自然速度，双手五指结构正确，背景结构稳定不扭曲变形，口型与台词准确对齐，无慢动作效果，眨眼自然真实。`
