## 一、 生成模式与首行对齐指令（Alignment Instruction）

根据输入资产的不同，MiniMax H3 内部支持四种生成模式。若使用首帧或首尾帧，**首行必须提供精确的时间对齐指令**，引擎据此将上传的图片绑定到对应的具体时间戳上：

### 1. I2VA（首帧图生视频 · 本 Skill 默认主力模式）
- **第一行对齐指令**：
  ```text
  For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.
  ```
  *(中文含义：在目标视频 0.00 秒处，完全参考 [Shot 1] 的首帧 <Picture 1>)*
- **核心路径**：**首帧锚点 → 动作起势 → 连续演变 → 动作收束/结果**。
- **禁忌**：不要在正文中重新描述首帧中已经固定的衣服花纹、发型细节，只写**从首帧开始的新增动作与镜头轨迹**。

### 2. FL2VA（首尾帧图生视频 · 动作受控模式）
- **第一行对齐指令**（`N` 为最后镜头编号，`S.SS` 为视频实际时长，保留两位小数）：
  ```text
  How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.
  ```
- **核心路径**：**首帧状态 → 可观察的中间变化 → 差异逐步收窄 → 尾帧精准着陆**。
- **调度原则**：首尾帧模式强烈建议**单镜头长镜头**，避免在插值过程中频繁切镜导致模型计算崩裂。

### 3. T2VA（纯文生视频）
- 无需首行对齐指令，直接从主描述字段与视觉风格起笔。

## 二、 全参考标签规范（Reference Labels）

在全参考模式下，上传的资产分为四类独立标签，**各类独立从 1 开始编号**，并在整篇提示词中含义保持唯一且稳定：

| 标签 | 官方定义 | 在本 Skill 中的具体对应 | 编写规范与必加排除项 |
|---|---|---|---|
| `<Subject N>` | 可复用的可见内容（人物、场景、服装、道具、风格） | 人物设定图、场景空镜图 | **必须同时写明正向职责与负向排除项**（见下文） |
| `<Picture N>` | 具体的单帧画面锚点（首帧、关键帧、尾帧） | 本段独立首帧（或尾帧） | 仅在作为实际帧画面时使用；纯人物/场景参考不得使用 Picture |
| `<Audio N>` | 独立的参考音频信号 | 从上一段抽取的音色参考 | 必须与说话人 ID 绑定：`<Audio 1> 是 <Subject 1> (S1) 的音色参考` |
| `<Video N>` | 视频编辑源或时序结构参考 | （本口播工作流暂不涉及） | 仅在直接视频续写或垫视频运镜时使用 |

### 关键避坑：正向职责与排除项（彻底解决背景串场与姿态锁死）
模型在解析人物参考图时，极易将参考图中的摄影棚背景、全身站立姿态也强制带入新视频中。因此在 `参考分工` 中，**必须加入明确的排除项**：
```text
<Subject 1> 是人物A，取自人物A设定图：锁定其面部五官轮廓、发型发色与服装材质；完全忽略原图中的纯色背景、站立姿态与镜头角度。
<Subject 2> 是场景1，取自场景1：锁定其建筑空间结构、陈设质感与主环境光线；完全忽略原图的空置构图，允许人物在空间中自然站位交互。
<Picture 1> 是 [Shot 1] 在 0.00 秒完全参考的首帧画面，负责锁定起始画幅构图、人物初始站位与首帧静态光影。
<Audio 1> 是 <Subject 1> (S1) 的音色参考，仅提取并参考其声线、音色厚度与语速节奏，绝不复用参考音频中的台词词句与环境噪音。
```

## 三、 视频提示词五大核心模块编写规则

按照官方 Video Prompt Writing Guide 标准结构，正文由五大块构成：

### 1. 参考分工（subject_definitions）
- 每个参考素材独立一行。
- 绑定 `<Subject N>`、`<Picture N>`、`<Audio N>` 与说话人 `(S1)`。
- 明确指出该资产负责锁定什么，同时明确指出排除什么。

### 2. 综合画面描述（integrated_multimodal_description / detailed_description）
这是视频的主体时间线，按播放时间顺序展开：
- **风格开篇**：放在最前（1-2句），定义全片调性（如：`写实商业摄影质感，现代大厂办公室自然采光，青灰冷色调微反差，画面通透逼真。`）。
- **镜头标记**：
  - 首镜无时间戳，直接写：`[Shot 1] 承接 <Picture 1> 的构图，<Subject 1> 保持首帧中的站位、服装与发型……`。
  - 段内若发生硬切转场（仅限必要正反打），后续镜头按时间递增格式书写：`[Shot 2] 在00:03.500，镜头切到……`。
- **秒级节拍细化**：在镜头内部，按 `0-3秒 / 3-7秒 / 7-10秒` 细化动作，符合真人真实生理运动耗时。
- **运镜三维矩阵（类型＋幅度＋速度）**：
  - 必须写成镜头内的自然动作句，严禁在句尾堆叠孤立标签。
  - **相机路径与主体运动速度绑定**：长镜头下运镜保持匀速平稳，复杂表演时机位保持稳定。
  - 词表对照：
    - `Push In / Pull Out`：推进 / 拉远（机位前后移动）
    - `Zoom In / Zoom Out`：变焦推近 / 变焦拉远（机身固定，改变焦距）
    - `Pan Left / Pan Right`：水平左摇 / 水平右摇（机位固定，镜头左右转动）
    - `Truck Left / Truck Right`：向左横移 / 向右横移（机位整体横向平移）
    - `Tilt Up / Tilt Down`：向上仰拍 / 向下俯拍（机位固定，镜头垂直上下俯仰）
    - `Pedestal Up / Pedestal Down`：升机 / 降机（机位整体垂直升降）
    - `Arc Shot`：弧线环绕镜头
    - `Tracking Shot`：跟拍镜头
    - `Static Shot`：固定镜头
    - `Shake Slightly`：轻微手持呼吸感晃动
    - 幅度：`小幅度 (with small amplitude)` / `大幅度 (with large amplitude)`
    - 速度：`慢速 (at slow speed)` / `快速 (at fast speed)`
    - *示例*：`镜头以小幅度慢速向[主角]推近，聚焦于面部微妙的犹疑表情。`
- **说话人与对白语法**：
  - 说话人编号：`(S1)`、`(S2)`，整部视频全程不变；两人合说使用 `(S1,S2)`。
  - 首次发声立声线：写明年龄、性别、音色质感（沉稳/清亮/沙哑）、语速与口吻。
  - 纯净台词标签：`<d>[中文] 原文台词。</d>`，标签内部只放语言与纯文字，**绝不放入任何语气、动作或括号注释**。
  - 标点规范：完整句子必须在 `</d>` 前使用标准标点（`。`、`？`、`！`）；**去除所有波浪号 `~`、Emoji 表情和装饰性标点**。
  - **台词后的闭口与微表情（极重要避坑）**：台词标签结束后，必须紧接人物口型与生理反应描述，例如：
    `<d>[中文] 我们上个季度的数据全都对不上。</d> 说话时口型准确对齐，台词结束后嘴唇自然闭合，眉头微蹙，轻轻呼出一口气。`
    （若不写嘴唇闭合，模型容易在说完整句话后继续无意识蠕动嘴唇或呆滞张口）。
  - 画外音规范：`以画外音说：<d>[中文] 台词。</d> 同时画面中人物嘴唇完全闭合。`
  - 跨切点台词：前后两处均使用 `<scenetrans>`，并注明声音无缝跨镜头连续。
  - 段尾截断台词：末尾使用 `<cutoff>`。
- **表演留白与微表情（拒绝木头人）**：台词间隙必须补充手部微动、胸腔呼吸起伏、眼神转移、眉毛微挑等可见微动作。
- **画面内可见文字**：仅当画面中真实出现招牌、手机屏保、海报时，用中文双引号标注，如 `电脑屏幕上显示“报表核算完毕”`。默认情况下在限制中声明不出现文字。

### 3. 整体环境声（overall_soundscape）
- 1–4 句连续自然段落。
- 专门汇总全片的物理环境声音：房间底噪（Room tone）、低频空调嗡鸣、窗外雨声、脚步声、衣物布料摩擦声、道具放置声、呼吸声。
- **严禁重复任何台词对白与画面内音乐**。若全片静音，写 `无` 或 `N/A`。

### 4. 画外配乐（non_diegetic_music）
- 1–3 句，专门描述仅观众能听见、角色听不见的背景配乐。
- **严禁使用抽象情绪词**（不要写“大气磅礴”、“高端奢华”、“悲伤焦虑”——音乐模型无法物理理解这些主观形容词）。
- **必须客观描述乐器、速度与动态走势**：
  - *乐器*：极简独奏钢琴、低沉大提琴持续长音铺底、清脆木吉他分解和弦、微弱电子合成器脉冲。
  - *速度*：慢速（60-80 BPM）/ 中速（90-110 BPM）/ 快速。
  - *动态*：音量平稳保持、片尾渐弱消隐（Fade out）、无突然强弱跳跃。
- 若无配乐，写 `无` 或 `N/A`。

### 5. 限制与物理锁定（Negative Constraints）
- 物理锁定与防崩标准句：
  `动作速度符合真人自然物理速度，双手五指结构完整且骨骼准确，背景空间结构稳定不扭曲变形，面部五官对称，口型与对白精准咬合对齐，无慢动作或抽帧跳跃，眨眼频率自然逼真。画面无多余画中画、无水印、无字幕。`

## 四、 社区与官方实操避坑指南（高完播率要诀）

### 1. 低成本验证法（Metaso 黄金实践）
不要一上来就用最高画质、最长时间批量跑片！
- **第一步**：先用低分辨率/快速试错模式，验证`<Picture 1>`首帧的机位、人物站位和运镜方向是否正确。
- **第二步**：**单次只微调一个变量**。如果人物动作变形，只调整动作描述的幅度和速度（如从“大幅度转身”降为“微侧头15度”），不要同时改动台词和运镜。
- **第三步**：主体、动作、空间关系完全稳定后，再提升画质渲染成片。

### 2. 跨段音色防串台
- 第2段使用的音色参考是从第1段成片中导出的，音频中往往带着第1段的原台词。
- 视频提示词的 `参考分工` 里必须明确声明：`仅提取其声线音色与语速节奏，不复用原音频中的对白内容`。
- 正文台词必须使用独立的 `<d>[中文] 本段新台词。</d>`，杜绝串词。

### 3. 镜头切分的物理原则
- 单镜头内只安排一种主运镜方式（避免既推又摇又升降的“晕车镜头”）。
- 动静结合：台词较长时，机位保持平稳微推，把舞台让给演员的面部微表情与台词口型；台词停顿间隙，再加入身体位移或环境动作。
